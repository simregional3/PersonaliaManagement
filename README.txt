PERSONALIA MANAGEMENT SYSTEM - REGIONAL 3
GitHub Pages starter files

CARA PAKAI:
1. Buka index.html.
2. Cari baris:
   const APP_URL = "PASTE_URL_WEB_APP_GOOGLE_APPS_SCRIPT_DI_SINI";
3. Ganti teks di dalam tanda kutip dengan URL Web App Google Apps Script Anda.
   Contoh format: https://script.google.com/macros/s/...../exec
4. Simpan index.html.
5. Upload seluruh isi folder/ZIP ini ke root repository GitHub (bukan folder pembungkusnya).
6. Di GitHub: Settings > Pages > Deploy from a branch > Branch: main > Folder: /(root) > Save.
7. Tunggu deployment selesai, lalu buka URL GitHub Pages yang diberikan GitHub.

CATATAN:
- Halaman ini hanya menjadi alamat depan/landing page dan mengarahkan pengguna ke Apps Script.
- Login, data Google Sheets, dan fungsi aplikasi tetap berjalan di Google Apps Script.
- Jangan masukkan password, token, atau data rahasia ke repository.
- Repository harus berisi index.html, favicon.ico, dan folder assets.
